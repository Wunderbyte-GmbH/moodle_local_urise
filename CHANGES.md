* Bugfix: Moodle 5.3: the web service local_urise_get_parent_categories uses the core_external\* classes instead of the deprecated global external_* classes (MDL-81225). Before, pages that describe every web service (Site administration > Server > Web services > API documentation, the test client) showed the developer notice "Class 'external_api' has been renamed for the autoloader and is now deprecated" for this class, which also failed Behat scenarios visiting these pages.
* Test: New PHPUnit test webservice_classes_test describes every function of db/services.php in a separate process and fails when loading its class raises a debugging notice.
* Improvement: On upgrade, every booking option with a price that is in the "24 hour mode" (waitforconfirmation = 2 with confirmationonnotification set: a freed seat is offered to the next person on the waiting list) is set to "Remove from waiting list when offer expires" (waitlistrecycling = 3). All other options keep their waiting list behaviour.
* Test: The new PHPUnit test upgrade_savepoints_test checks the version numbers in db/upgrade.php: every step ends with the savepoint of its own number and the numbers only go up, the highest step is not above the plugin version, and steps that are not part of the last release (the git tag with the highest plugin version) have a number above it. The last check needs the git tags and is skipped without them.
* Bugfix: The search of the course shortcodes found courses by the user id of their teachers and by technical terms: a search for "81" listed every course of the teacher with the user id 81, a search for "firstname" or "name" listed every course with a teacher. The search read the column teacherobjects, which holds the teachers as JSON. Teachers are now searched in the column teachernames of mod_booking, which only holds their names, so they are found by first name and last name in any order and by nothing else.
* Requires a mod_booking version newer than 10.0.8 (2026110602): the search relies on the new column teachernames of the booking options SQL.
* Test: PHPUnit test for the search by teacher of [unifiedlist], [unifiedcards] and [unifiedtextlist] (names are found in any order of the words, user ids and the keys of the JSON are not). The CI workflow installs tool_mocktesttime, which the test data generator of mod_booking needs.
