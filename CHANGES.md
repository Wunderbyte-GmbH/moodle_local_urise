* Bugfix: The search of the course shortcodes found courses by the user id of their teachers and by technical terms: a search for "81" listed every course of the teacher with the user id 81, a search for "firstname" or "name" listed every course with a teacher. The search read the column teacherobjects, which holds the teachers as JSON. Teachers are now searched in the column teachernames of mod_booking, which only holds their names, so they are found by first name and last name in any order and by nothing else.
* Requires a mod_booking version newer than 10.0.8 (2026110602): the search relies on the new column teachernames of the booking options SQL.
* Test: PHPUnit test for the search by teacher of [unifiedlist], [unifiedcards] and [unifiedtextlist] (names are found in any order of the words, user ids and the keys of the JSON are not). The CI workflow installs tool_mocktesttime, which the test data generator of mod_booking needs.
